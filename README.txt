ACRS V4 — COMPLETE INTERACTIVE CPS DEMO

Run index.html with VS Code Live Server (Ritwick Dey).

FEATURES
1. Emergency Command Center: Interactive simulation featuring 300 land-based citizens, 40 smart bunkers, 30 rail stations, and active response units.
2. AI Decision Engine: Real-time route optimization using multi-factor scoring (distance, road traffic congestion, bunker capacity, and active danger zones).
3. Multi-Modal Route Calculation: Dynamic Citizen → Rail → Bunker safest pathing with drag-and-drop citizen positioning.
Network & Transit Planner: Live crowd heatmap demand modeling, 3 interconnected metro line simulations, and emergency train deployment controls.
4. Citizen Mobile App Interface: Location-aware citizen view offering real-time alerts, GPS verification status, and step-by-step guidance.
5. Cybersecurity Operations Console: Simulated cyber-physical attack vectors (GPS Spoofing, False Sensor Readings, DDoS) with automated detection and mitigation mechanisms.

QUICK DEMO GUIDE
1. Drag a Citizen: Click and drag any citizen marker on the command map to automatically trigger and display the safest route to an open bunker.
2. Activate Incident: Select an emergency type (Building Fire, Flood, Chemical Leak, or Infrastructure Failure) and click Activate Incident.
3. Run Full Scenario: Click Run Full Scenario to observe end-to-end incident activation, route recalculation, evacuation execution, and threat mitigation.
4. Inspect Transit: Navigate to the Network Planner tab to view crowd heatmaps, recalculate metro lines, or deploy extra trains.
5. Simulate Cyber Attacks: Open the Cybersecurity tab to launch GPS spoofing, false sensor readings, or DDoS simulations and view real-time mitigations.

This is an educational simulation; population, incidents, traffic, crowd levels and cyber events are simulated.
